# 浏览器插件开发经验规范

## 使用顺序：通用规则＋当前场景

这里的插件指浏览器扩展及其页面增强功能，不泛指后端插件框架。先读取目标扩展的规则、说明、Manifest、相关代码及 Git 状态，确认浏览器、安装方式和本次改动范围。

通用规则约束当前功能如何实现，不要求每个插件都有侧栏、设置、持久化、登录、采集或通知。项目已有某项功能，也不表示每次局部改动都要重新验收整套链路。没有涉及的内容跳过；涉及但未验证的事项如实说明，不能当作“不适用”。

## 通用规则（所有扩展按本次受影响范围执行）

1. **界面功能完整可达。** 文字、输入和按钮不被裁切、遮挡或压成竖排窄条；长内容可滚动、展开或进入详情，不要求塞进一屏。弹窗正文滚动时，标题、关闭和主要操作可达。
2. **按用途选择容器。** 需要持续浏览网页并操作的工具优先浏览器原生侧栏；一次性快捷操作可用弹窗，大量结果可用独立管理页。不要默认都做一套。侧栏宽度调整和浏览器缩放属于 PC 验收，不能因暂不做手机而跳过；不能把来源项目的固定像素宽度套用所有插件。侧栏左右位置尊重浏览器能力和用户设置。
3. **不破坏原网页与编辑状态。** 不无故抢焦点、键盘或滚轮；更新不关闭正在操作的下拉框、不清空未保存输入、不重置无关筛选和滚动。面板有明确的收起或关闭入口；关闭界面不暗中等于停止任务。
4. **入口复用核心能力。** 确有侧栏、弹窗或管理页多个入口时，共享相关数据、设置和操作逻辑；布局可不同，不复制整套业务。界面是否保留、恢复或清理状态应明确，未涉及的状态存储不新增。
5. **权限与能力匹配。** 只申请功能必需的网站和浏览器权限；`debugger`、全部网站权限、Cookie 访问不是默认配置。确认目标浏览器和 API 支持范围，缺少能力时给出中文提示或符合需求的降级方案，不声称所有浏览器兼容。
6. **保护运行边界。** 根据实际功能区分扩展界面、后台和内容脚本职责；跨边界消息校验类型、参数、发送来源和必要的标签／文档身份，不把网页消息变成任意执行、请求代理或凭据读取入口。不依赖内容脚本可以直接读取网页脚本私有变量的假设。
7. **错误与结果可判断。** 分开显示进行中、成功为空、失败、无权限和结果不确定；失败不能显示假 0 或假成功。诊断说明阶段与可处理原因，不输出真实密码、Cookie、Token、Webhook 或完整认证请求。不把插件本地存储、混淆或包内加密当作对使用者保密的保证。
8. **安装更新和验收有证据。** 改动后按项目命令检查并打包运行必需文件，包含实际依赖，排除凭据、用户数据、日志和测试产物。升级默认保留原设置；涉及数据格式变化时再做兼容迁移。通过目标浏览器真实扩展入口验证受影响功能；直接打开 HTML 或模拟后台不能证明权限、后台、注入及真实侧栏可用。只交付已验证内容，并说明需要重载扩展、刷新页面或重新授权的步骤；用户无需开发时的调试工具。

### 网页增强（仅在注入或读取网页时）

- 限定目标站点和页面范围；注入样式用命名空间或适合项目的隔离方式，避免改坏宿主网页。
- 处理不刷新整页的路由变化、DOM 异步加载和重复注入；清理过期监听，不重复生成面板和按钮。
- 监听原有 fetch/XHR 等请求时，不消费原响应、不改变返回值和网页行为；仅传递必要字段。页面提供的线索仍需校验，不能直接证明敏感操作被授权。
- 操作前后绑定并核对真实标签、文档和业务对象，防止用户切页或目标导航后操作另一对象。

### 本地状态（仅在需要保存或恢复时）

- 明确临时界面状态、持久设置和业务结果的保存范围。使用适合目标浏览器的存储机制；不默认增加云服务。
- 升级或重开时回填现有值；清空、删除和卸载的后果说明清楚，不以卸载重装代替普通程序升级。
- 后台需要跨休眠／重启恢复时保存必要检查点；承认浏览器可能终止后台执行，不靠内存变量或普通定时器承诺长期在线。

## 经验来源与维护

通用界面和采集经验来自既有采集扩展中弹窗窄条、操作栏遮挡、侧栏入口、下拉框被刷新打断等记录；账号场景来自网站在线助手的账号填写、会话判断和恢复设计。部分链路只有模拟或隔离验证，不能称作已经真实网站验收通过；已取消方案不作为当前模板。

具体目标域名、账号编号、请求参数、密码保存偏好、间隔和通知配置不成为跨项目默认值。只有本次明确需要或用户授权才启用相应场景，不把条件模块升级为所有插件的强制要求。

平台机制参考：[Chrome 侧栏](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[扩展后台生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)、[内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Edge 侧栏](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/sidebar)。采用具体 API 时核实目标版本，不照搬历史版本限制。
